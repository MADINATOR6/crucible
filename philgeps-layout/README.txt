PhilGEPS Print Layout Helper

INSTALL
1. Unzip this folder somewhere you will keep it.
2. In Chrome, open chrome://extensions and turn on Developer mode.
3. Press "Load unpacked" and choose the unzipped folder.
4. Open a PhilGEPS printable format. The sidebar appears on the right of the popup tab.

END DATE
Enter the proceed date in the End date section of the sidebar. The end date is the same date next month. If next
month has no such date, it uses that month's last day. If the date falls on a Saturday, Sunday or holiday, it moves
to the next working day.

Holidays loaded: 2026 and 2027, from the official proclamations. A date reaching any other year shows "Not confirmed".
The 2027 Eid dates are not proclaimed yet, so 2027 results show a warning until you add them under "Add a non-working
day". Add one-town holidays the same way. Tick the NCR box only if the Metro Manila days apply to you.

UPDATING THE HOLIDAYS
Edit holidays.js and copy each date from the official proclamation, then reload the extension. Each entry carries the
weekday the proclamation prints, so a mistyped date fails the tests.
